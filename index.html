About the Project

Fast & Serverless

Static files (HTML and CSS) are served directly through GitHub Pages CDN with zero server configuration or hosting cost.

Git-Based Publishing

Workflow

GitHub Pages Deployment Workflow

How static code travels from local workstation to global web availability.

01

Local Development

Author clean HTML5 and CSS3 files, validating visual layout, contrast, and navigation links locally.

02

Commit & Push

Stage local changes with git add, create descriptive commits, and push to the remote main branch on GitHub.

03

GitHub Pages Build

GitHub Pages automatically detects new commits pushed to the main branch and triggers the static publishing action.

04

Live Production

The updated website is live immediately at mythreyan26.github.io/devops-static-website/.
